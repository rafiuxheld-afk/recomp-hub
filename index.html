Recomp Hub

Recomp Hub é um aplicativo gratuito para Windows que reúne num só lugar os jogos com recompilações e decompilações publicadas no GitHub: lista os projetos, baixa as versões oficiais direto dos repositórios, ajuda a organizar suas próprias ROMs/discos e mods, e integra RetroAchievements e Steam.

O login com Google ou GitHub serve apenas para identificar você no app e, se você quiser, guardar um backup das suas configurações na sua própria conta.
