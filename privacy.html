Política de Privacidade

Última atualização: 16 de outubro de 2026

O Recomp Hub é um aplicativo de desktop para Windows. Ele não tem servidor próprio: tudo o que ele guarda fica no seu computador ou na sua própria conta de nuvem.

Dados que acessamos

  • Login com Google: nome, e-mail e foto do perfil (escopos openid, email, profile), usados só para mostrar quem está conectado no app.
  • Backup opcional no Google Drive: o escopo drive.appdata permite ao app criar e ler apenas a pasta oculta de configurações dele no seu Drive. O app não vê nenhum outro arquivo seu.
  • Login com GitHub: nome de usuário e foto públicos, e um token usado para consultar as versões dos jogos no GitHub.

Como os dados são guardados

Os tokens de acesso ficam no seu computador, cifrados com a proteção de dados do Windows (DPAPI), e só abrem no seu usuário do Windows. Nenhum dado é enviado ao desenvolvedor nem a terceiros, e nada é vendido ou usado para publicidade.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover

Saia da conta pelo app (Sua conta → Sair) ou revogue o acesso em myaccount.google.com/permissions ou nas configurações de aplicativos do GitHub. Desinstalar o app e apagar a pasta %LOCALAPPDATA%\RecompHub remove todos os dados locais.
